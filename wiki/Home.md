# Infra Pilot

Modular orchestration framework for containers, cloud, and game servers — via CLI, web, or Discord.

## Quick Start

```bash
git clone https://github.com/drosemann/infra-pilot.git
cd infra-pilot && cp .env.example .env
docker compose up -d
```

| Service | URL |
|---------|-----|
| Panel | http://localhost:5173 |
| API | http://localhost:3001 |
